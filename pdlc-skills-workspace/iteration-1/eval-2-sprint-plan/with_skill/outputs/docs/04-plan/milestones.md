## 1. 확정 사항

- **핵심 구현 기능 3개**: FEAT-001 (매장 등록·설정), FEAT-002 (QR 도장 적립), FEAT-003 (쿠폰 자동 발행·사용 처리)
  - 선정 근거: ① Must 요구사항 REQ-001~003 커버, ② 프로젝트 성공 기준인 "발행→적립→사용 여정 5분 내 완주"를 3개가 하나의 연결된 사용자 여정(user journey)으로 완성, ③ 온보딩·적립·발행/사용으로 구현 난이도 균형.
- **탈락 후보와 사유**:
  - FEAT-004 (손님용 적립 현황 페이지) — Must(REQ-004)이나 핵심 여정 완주에 필수가 아님. FEAT-002 적립 완료 화면에 현재 도장·쿠폰 수를 표시해 부분 대체하고, 6단계 이후 여유 시 최우선 추가.
  - FEAT-005 (통계 대시보드) — Should. MVP 검증에 불필요, 데이터가 쌓인 뒤에 의미 있음.
- **인증 처리**: 이메일 로그인·RLS는 "기능 3개"에 포함하지 않되 기반 작업(foundation)으로 일정에 반영 (WBS #4).
- **전체 기간**: 2026-07-06 ~ 2026-08-14 (6주, 근무일 30일 = 작업 25일 + **버퍼 5일, 16.7%**)
