# 프로젝트 헌장 (Project Charter) — RunMate

- **작성일**: 2026-07-02
- **기간**: 2026-07-02 ~ 2026-08-12 (6주)
- **팀**: 1인 (기획/디자인/개발/운영 겸임)
- **상태**: ✅ 킥오프 확정

---

## 1. 한 줄 정의

> **"혼자 뛰기 싫은 러너가, 내 동네·내 페이스에 맞는 러닝 크루를 5분 안에 찾아 함께 뛰게 해주는 앱"**

## 2. 배경 & 문제 정의

- 러닝 인구는 늘고 있지만, 크루 모집은 인스타그램 DM·오픈카톡·네이버 카페에 파편화되어 있다.
- 기존 채널의 문제:
  - **탐색 비용**: 지역·요일·페이스 조건으로 검색이 불가능하다.
  - **미스매치**: 가입해보니 페이스가 안 맞아 민폐가 될까 봐 이탈한다 (초보 러너의 최대 진입장벽).
  - **일정 관리 부재**: 정기 러닝 일정과 참석 여부를 카톡 공지로만 관리한다.

## 3. 목표 (이 프로젝트가 성공했다고 말할 수 있는 조건)

### 3.1 제품 목표
| # | 목표 | 측정 기준 |
|---|---|---|
| G1 | 동작하는 MVP를 실제 URL로 배포 | 누구나 접속해 가입→크루 탐색→가입 신청→세션 참석 응답까지 가능 |
| G2 | 핵심 플로우 완주율 | 시연 시나리오(회원가입→크루 매칭→일정 확인)가 막힘 없이 동작 |
| G3 | 기본 품질 | 핵심 로직 테스트 커버, Lighthouse 성능/접근성 80점 이상 |

### 3.2 포트폴리오 목표 (진짜 최종 산출물)
| # | 목표 | 산출물 |
|---|---|---|
| P1 | 문제 정의→해결 과정을 보여주는 케이스 스터디 | README + 케이스 스터디 문서 |
| P2 | 기술 의사결정 근거 문서화 | ADR 3건 이상 |
| P3 | 시연 가능한 자료 | 2~3분 데모 영상 + 라이브 URL + 스크린샷 GIF |
| P4 | 개발 프로세스 증빙 | 커밋 히스토리, PR, CI 배지, 이슈 트래킹 기록 |

### 3.3 비목표 (Non-Goals) — 6주 안에 하지 않는 것
- ❌ 네이티브 앱 (iOS/Android 스토어 출시) → **모바일 우선 반응형 웹앱**으로 대체
- ❌ 실시간 채팅 (크루 내 소통은 외부 오픈카톡 링크 필드로 대체)
- ❌ GPS 러닝 기록/트래킹 (Strava가 아님 — 우리는 "매칭"에 집중)
- ❌ 결제/멤버십, 푸시 알림, 소셜 로그인 3종 이상, 관리자 어드민 고도화
- ❌ 실사용자 획득 마케팅 (포트폴리오가 목적, 그로스가 아님)

## 4. 범위 (Scope) — MVP 기능 요약

| 우선순위 | 기능 | 설명 |
|---|---|---|
| P0 | 인증 | 이메일(또는 소셜 1종) 가입/로그인 |
| P0 | 러너 프로필 | 활동 지역, 평균 페이스, 선호 시간대/요일, 러닝 목적 |
| P0 | 크루 생성/관리 | 크루장이 크루 개설 (지역, 정기 요일, 페이스 밴드, 정원, 소개) |
| P0 | 크루 탐색 | 목록 + 필터(지역/요일/페이스/모집상태), 상세 페이지 |
| P0 | 매칭(가입 신청/승인) | 러너가 신청 → 크루장이 승인/거절 |
| P1 | 러닝 세션(일정) | 크루 내 정기/단발 러닝 일정 생성, 참석/불참 응답 |
| P1 | 추천 정렬 | 내 프로필(지역·페이스) 기반 크루 추천 정렬 |
| P2 | 크루 후기/분위기 태그 | 가입 전 크루 분위기 파악용 (시간 남으면) |

상세 명세는 [prd-mvp.md](prd-mvp.md) 참고.

## 7. 운영 원칙 (1인 프로젝트 규칙)

1. **주당 투입 시간**: 평일 2시간 × 5 + 주말 4시간 ≈ **주 14시간** 기준으로 스코프 산정
2. **금요일은 마일스톤 점검일**: 매주 금요일 진행률 체크 → 지연 시 P1부터 삭제 (일정은 고정, 범위가 변수)
3. **main은 항상 배포 가능**: 모든 변경은 PR + CI 통과 후 머지
4. **문서는 코드와 함께**: 큰 결정은 그 주에 ADR로 기록 (나중에 몰아 쓰지 않기)
5. **완벽보다 완결**: 기능 하나를 끝까지(UI+API+테스트+배포) 관통시킨 후 다음 기능으로
