## 3. 기능 상세 (요약)

### FEAT-001: 매장 등록·설정 ★
사장님이 이메일 로그인 후 매장명, 적립 정책(도장 N개 → 쿠폰 1개)을 설정한다. 정상 플로우 4단계, 오류: 중복 매장명(POL-001).

### FEAT-002: QR 기반 도장 적립 ★
매장 고유 QR을 손님이 스캔 → 전화번호 뒤 4자리 입력 → 도장 1개 적립. 오류: 하루 중복 적립 제한(POL-002), 잘못된 QR(POL-003).

### FEAT-003: 쿠폰 자동 발행·사용 처리 ★
도장이 정책 개수에 도달하면 쿠폰 자동 발행. 사용 시 사장님 화면에서 사용 처리. 오류: 이미 사용된 쿠폰 재사용 시도(POL-004), 만료 쿠폰(POL-005).

### FEAT-004: 손님용 적립 현황 페이지 ★
손님이 전화번호로 자기 도장·쿠폰 현황 조회. 오류: 미등록 번호 안내.

### FEAT-005: 사장님 통계 대시보드
기간별 적립·사용 수치. (Should — 이번 구현 후보 아님이 아니라 후보 경합 대상)
