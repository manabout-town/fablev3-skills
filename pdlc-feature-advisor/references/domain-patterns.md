# 도메인별 검증 기능 패턴 라이브러리

스킬이 제안을 생성할 때 참조하는 도메인별 패턴 목록. 각 패턴은 실제 서비스에서 검증된 것만 포함한다. "이 도메인이면 이 기능이 있어야 한다"는 체크리스트가 아니라, 갭 분석 후 연결할 수 있는 후보 풀이다.

---

## 커머스 (E-Commerce)

### 전환율 개선
| 패턴 | 핵심 동작 | 검증 사례 | 타깃 지표 |
|------|-----------|-----------|-----------|
| 장바구니 이탈 복구 이메일/푸시 | 미결제 24시간 후 알림 + 쿠폰 | 쿠팡, Shopify 기본 | 전환율 +5~15% |
| 가챠형 쿠폰 박스 | 결제 전 랜덤 할인 뽑기 | 올리브영 앱, 무신사 | 전환율 +10~20%, 앱 재방문 |
| 긴급성 트리거 | "N명이 보고 있어요", 재고 N개 남음 | 야놀자, 쿠팡 | 즉시 구매 전환 |
| 소셜 증거 강화 | 실시간 구매 피드, 리뷰 수 강조 | 크림, 에이블리 | 신뢰도 → 전환율 |
| 원클릭 재구매 | 이전 주문 기반 "또 주문하기" | 쿠팡 로켓, 마켓컬리 | 재구매율 +20~30% |

### 리텐션 개선
| 패턴 | 핵심 동작 | 검증 사례 | 타깃 지표 |
|------|-----------|-----------|-----------|
| 구매 후 리뷰 + 포인트 | 리뷰 작성 시 적립금 지급 | 무신사, 올리브영 | 재방문율, UGC 생성 |
| 포인트/등급 시스템 | 누적 구매액 기반 등급, 혜택 차등 | 현대백화점, SSG | LTV, 이탈 방지 |
| 위시리스트 + 가격 알림 | 관심 상품 저장 → 가격 하락 알림 | 네이버 쇼핑, 쿠팡 | 재방문, 전환율 |
| 개인화 추천 피드 | 구매/조회 이력 기반 상품 큐레이션 | 에이블리, 지그재그 | 세션 시간, 전환율 |
| 정기구독 | 소모품 자동 재주문 | 마켓컬리, 쿠팡 로켓 | LTV, 예측 가능 수익 |

### 객단가 개선
| 패턴 | 핵심 동작 | 검증 사례 | 타깃 지표 |
|------|-----------|-----------|-----------|
| 번들 / 세트 구성 | 함께 사면 할인 | 올리브영 세트, CJ온마트 | 객단가 +15~30% |
| 무료배송 임계값 유도 | "N원 더 담으면 무료배송" 바 | 대부분의 커머스 | 객단가 +10~20% |
| 크로스셀 추천 | "이 상품과 함께 많이 산" | 아마존, 쿠팡 | 객단가 +8~15% |

### 바이럴
| 패턴 | 핵심 동작 | 검증 사례 | 타깃 지표 |
|------|-----------|-----------|-----------|
| 친구 초대 리워드 | 초대한 사람·받은 사람 모두 쿠폰 | 토스, 당근마켓 | CAC 절감, 신규 유저 |
| 구매 인증 공유 | SNS 공유 시 추가 포인트 | 무신사, 스타벅스 | 바이럴 계수 |
| 공동구매 / 소셜 딜 | N명 모이면 가격 하락 | 티몬 초기, 핀둬둬 | 바이럴 + 전환율 |

## 소셜 / 커뮤니티

### 참여 심화
| 패턴 | 핵심 동작 | 검증 사례 | 타깃 지표 |
|------|-----------|-----------|-----------|
| 스트릭 / 연속 출석 | 매일 접속 시 보상 누적, N일 끊기면 리셋 | 듀오링고, 클래스101 | DAU, 리텐션 |
| 뱃지 / 칭호 시스템 | 활동 달성 시 칭호 부여, 프로필 표시 | Reddit, 스택오버플로우 | 참여율, 정체성 형성 |
| 랭킹 / 리더보드 | 주간·월간 활동량 순위 | 런키퍼, 포레스트 | 경쟁심 → 재방문 |
| 챌린지 / 미션 | 기간 한정 공동 목표 | 카카오뱅크 챌린지, 클래스101 | 단기 DAU 급상승 |
| 전문가 Q&A / AMA | 특정 유저(전문가)에게 질문 | 블라인드, 오픈채팅 | 고품질 UGC, 체류 시간 |

### 콘텐츠 생성 장려
| 패턴 | 핵심 동작 | 검증 사례 | 타깃 지표 |
|------|-----------|-----------|-----------|
| 콘텐츠 수익화 | 인기 게시물 작성자에게 포인트/현금 | 네이버 블로그, 브런치 | 고품질 UGC 증가 |
| 템플릿 제공 | 글 쓰기 쉬운 구조화된 양식 | 오늘의집, 당근 | 콘텐츠 생성 허들 낮춤 |
| 큐레이션 주간 픽 | 운영진이 우수 게시물 선정·홍보 | 브런치 에디터 픽 | 작성 동기 부여 |

## 예약·매칭 플랫폼

### 매칭 품질
| 패턴 | 핵심 동작 | 검증 사례 | 타깃 지표 |
|------|-----------|-----------|-----------|
| 필터 고도화 | 다차원 조건 설정 (가격·거리·평점·가용시간) | 에어비앤비, 숨고 | 매칭 만족도, 재이용율 |
| 즉시 예약 vs 견적 요청 | 공급자 설정에 따라 두 경로 분기 | 크몽, 숨고 | 전환율, 공급자 만족도 |
| 프로필 신뢰도 표시 | 인증 뱃지, 응답률, 평균 응답 시간 | 에어비앤비, 당근 | 전환율, 안전 신호 |

### 리텐션
| 패턴 | 핵심 동작 | 검증 사례 | 타깃 지표 |
|------|-----------|-----------|-----------|
| 즐겨찾기 + 재예약 알림 | 이전 이용 공급자 알림 | 카카오헤어샵 | 재예약율 |
| 예약 후 리마인더 | D-1, 당일 아침 푸시 | 야놀자, 네이버 예약 | 노쇼율 감소 |
| 취소 패널티 / 보증 | 취소율 낮추는 정책 + UI | 에어비앤비 | 공급자 이탈 방지 |

## 생산성 / SaaS

### 온보딩
| 패턴 | 핵심 동작 | 검증 사례 | 타깃 지표 |
|------|-----------|-----------|-----------|
| 인터랙티브 튜토리얼 | 실제 기능을 직접 써보며 배우는 온보딩 | Notion, Linear | 활성화율(D1 리텐션) |
| 진행 체크리스트 | "3단계 완료하면 시작!" 형태 | HubSpot, Trello | 온보딩 완주율 |
| 샘플 데이터 제공 | 빈 화면 대신 예시 콘텐츠로 시작 | Notion, Airtable | 첫 핵심 행동까지 시간 단축 |

### 협업·확장
| 패턴 | 핵심 동작 | 검증 사례 | 타깃 지표 |
|------|-----------|-----------|-----------|
| 팀 초대 | 사용자가 팀원 초대 → 조직 단위 확산 | Slack, Notion | 바이럴, 계정당 좌석 수 |
| 템플릿 마켓 | 사용자가 만든 템플릿 공유/판매 | Notion, Figma | 참여도, 생태계 형성 |
| 외부 연동 | Slack, 캘린더, GitHub 등 웹훅 | Linear, Zapier | 이탈 방지(switching cost) |

### 수익화
| 패턴 | 핵심 동작 | 검증 사례 | 타깃 지표 |
|------|-----------|-----------|-----------|
| Freemium 제한 | 핵심 기능은 무료, 고급 기능 유료 | Notion, Canva | 전환율(무료→유료) |
| 사용량 기반 과금 | API 호출 수, 파일 용량 등 | AWS, Vercel | 수익 예측 가능성 |

## 도메인 분류 기준

서비스가 여러 도메인에 걸치면 가장 강한 수익 모델과 핵심 행동이 속한 도메인을 주 도메인으로 분류하고, 나머지를 보조로 참조한다.

| 키워드 | 도메인 |
|--------|--------|
| 상품, 결제, 배송, 장바구니, 주문 | 커머스 |
| 게시글, 댓글, 팔로우, 피드, 커뮤니티 | 소셜/커뮤니티 |
| 예약, 견적, 매칭, 공급자, 공간 | 예약·매칭 |
| 워크스페이스, 팀, 프로젝트, 대시보드 | 생산성/SaaS |
| 아티클, 영상, 오디오, 구독, 콘텐츠 | 콘텐츠/미디어 |
