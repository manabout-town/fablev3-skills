# 정책서 엣지케이스 체크리스트

서비스에 해당하는 영역만 골라 POL로 작성한다. "해당 없음"도 판단 근거와 함께 기록하면 리뷰가 쉬워진다.

## 계정과 인증
- [ ] 회원가입 조건 (연령, 중복 계정, 이메일 인증 여부)
- [ ] 로그인 실패 처리 (횟수 제한, 잠금, 해제 방법)
- [ ] 비밀번호 규칙과 재설정 절차
- [ ] 회원 탈퇴: 즉시 삭제 vs 유예 기간, 작성 콘텐츠 처리, 재가입 제한
- [ ] 휴면 계정 처리 (기준 기간, 사전 통지)

## 권한과 접근
- [ ] 역할(role) 정의와 역할별 가능 행위 매트릭스
- [ ] 권한 없는 접근 시 동작 (숨김 vs 안내 vs 리다이렉트)
- [ ] 소유권 이전 (작성자 탈퇴 시, 관리자 변경 시)

## 데이터 생명주기
- [ ] 생성 제한 (개수, 용량, 빈도 — rate limit)
- [ ] 수정 가능 조건과 이력 보존 여부
- [ ] 삭제: soft delete vs hard delete, 복구 가능 기간
- [ ] 연쇄 삭제 (부모 삭제 시 자식 데이터)

## 동시성과 중복
- [ ] 중복 제출 (더블 클릭, 새로고침 재전송)
- [ ] 동시 수정 충돌 (마지막 저장 승리 vs 잠금)
- [ ] 재고/정원 등 한정 자원의 동시 신청

## 금전 (해당 시)
- [ ] 결제 실패·중단 처리
- [ ] 환불 조건과 기한
- [ ] 부분 취소, 포인트/쿠폰 병용 규칙

## 콘텐츠와 운영
- [ ] 금칙어, 신고 처리 절차와 기준
- [ ] 운영자 개입 권한 (숨김, 삭제, 계정 정지)와 이용자 이의 절차

## 알림과 커뮤니케이션
- [ ] 알림 종류별 발송 조건과 수신 거부 범위 (필수 고지 vs 마케팅)

## 법규 (한국 기준)
- [ ] 개인정보: 수집 항목/목적/보관 기간/파기 (개인정보보호법)
- [ ] 만 14세 미만 가입 처리
- [ ] 전자상거래법 (거래 시): 청약철회, 표시 의무
- [ ] 위치정보 사용 시 별도 동의

## 시스템 경계
- [ ] 외부 API 장애 시 폴백 (예: 소셜 로그인 불가 시)
- [ ] 점검 시간 처리
- [ ] 타임존, 날짜 경계 (자정 넘김, 월말)
