## 심각도/우선순위 기준표

| 심각도 | 기준 |
|---|---|
| Critical | 핵심 기능 불능, 데이터 손실·유출, 보안 |
| Major | 주요 플로우 우회로만 가능, 잘못된 데이터 표시 |
| Minor | 기능은 되나 UX 결함, 문구 오류 |
| Trivial | 시각적 미세 결함 |

| 우선순위 | 기준 |
|---|---|
| P1 | 즉시 수정 (다음 작업 전) |
| P2 | 이번 단계 내 수정 |
| P3 | 백로그 이월 가능, 7단계 개선 계획에 포함 검토 |
| P4 | 수정 안 해도 무방, 기록만 |
